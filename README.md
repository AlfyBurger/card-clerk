# Eldritch Horror Card Clerk+ (offline iPhone web app)

An offline-capable version of [Eldritch Horror Card Clerk+](https://github.com/metapone/eldritch-horror-card-clerk-plus)
by metapone (based on Eldritch Horror Card Clerk by Magnus Rydin), with all expansions always included.

Open the GitHub Pages address in Safari on iPhone → Share → Add to Home Screen, then open it once from the
Home Screen while online. After that it works without internet.
